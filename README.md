# Hand Gesture Volume Control 🎛️

Control your system volume using hand gestures via webcam.

## Features
- Real-time hand tracking
- Volume control using finger distance
- Uses OpenCV + MediaPipe

## Requirements
- Python 3.x
- Webcam

## Installation

git clone https://github.com/suhaani09/Hand-gesture-volume.git
cd Hand-gesture-volume

pip install -r requirements.txt

## Run

python main.py
